# Machine Learning for Macroeconomic Regime Identification

An R-based project to identify shifts in macroeconomic regimes using machine learning methods. Currently based on 'Taylor-rule' variables - real output, inflation, and short-term interest rates. 

## Data 
* **Global Macroeconomic Database:** See [this](https://www.globalmacrodata.com/)
* **Frequency:** Annual

## Methods
* **Time Series Econometrics:** Unit Roots, Stationarity, Structural Breaks 
* **Unsupervised Machine Learning Algorithms**:
  * K-Means Clustering
  * Gaussian Mixture Model (GMM)
  * Density-Based Spatial Clustering of Applications with Noise (DBSCAN)
  * Hidden Markov Model (HMM) 


## Older Work - India Focus

* **Quarterly Data:** Seasonal Adjustment, Y-o-Y changes, scaling for (quarterly) data to capture macro-financial 'regimes'.
